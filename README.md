# Hugo's Paella

Website voor Hugo's Paella, live op [hugopaella.nl](https://hugopaella.nl)
(Nederlands) en [hugopaella.nl/es](https://hugopaella.nl/es) (Spaans, nog de
oude "in aanbouw"-pagina).

Statische site, geen build-stap nodig: bestanden aanpassen, committen en
pushen is genoeg, GitHub Pages doet de rest.

## Structuur

- `index.html` — Home
- `paella-op-locatie/` — Paella op locatie (incl. FAQ-accordion, prijstabel)
- `de-paella/` — De Paella (oorsprong, techniek, link naar calculator)
- `over-hugo/` — Over Hugo (tijdlijn)
- `blog/` — Blog-overzicht + losse artikelen per submap
- `calculator/` — Placeholder voor de Paella Receptencalculator (nog te bouwen)
- `contact/` — Contactformulier (submit-actie is nu een placeholder, nog te
  koppelen aan een verzendoplossing zoals Formspree)
- `es/` — Spaanse versie: nog de oude "binnenkort meer"-pagina, wordt in een
  aparte stap bijgewerkt zodra de Nederlandse content definitief is
- `css/style.css` — alle styling (huisstijl v05)
- `assets/img/`, `assets/video/` — foto's en video's

## Nog te doen

- Spaanse vertaling van alle nieuwe pagina's onder `es/`
- Contactformulier koppelen aan een echte verzendoplossing
- Paella Receptencalculator (rekenlogica volgt apart)
- Losse receptpagina's per gerecht (Valenciana, Marisco, Verduras, Fideuà)
- Twee blogartikelen ("mini-paella's van 15 cm" en "Op bezoek in Valencia")
