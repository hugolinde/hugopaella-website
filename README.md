# Hugo's Paella

Tijdelijke "under construction"-website voor Hugo's Paella, live op
[hugopaella.nl](https://hugopaella.nl) (Nederlands) en
[hugopaella.nl/es](https://hugopaella.nl/es) (Spaans).

Statische site: `index.html`, `es/index.html`, `css/style.css` en de foto's/video's
in `assets/`. Geen build-stap nodig — bestanden aanpassen, committen en pushen is
genoeg, GitHub Pages doet de rest.
